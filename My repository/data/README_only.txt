OULAD data are intentionally not stored in this repository.

Download the anonymised Open University Learning Analytics Dataset (OULAD) from:
https://analyse.kmi.open.ac.uk/open_dataset

Alternatively, the dataset is archived on Figshare:
https://doi.org/10.6084/m9.figshare.5081998

Place the seven CSV files in:
data/raw/

Required files:
- courses.csv
- assessments.csv
- studentAssessment.csv
- studentInfo.csv
- studentRegistration.csv
- vle.csv
- studentVle.csv
